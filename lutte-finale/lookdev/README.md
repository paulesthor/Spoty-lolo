# Look-dev (tests de direction artistique)

Scène de test "Hypermarché" rendue dans plusieurs styles. Style retenu : **F** (fin de journée), caméra **mid**.

```
godot --path . -- style=F cam=mid out=res://shots/F_mid.png
```

Styles : A (jouet coloré), B (affiche), C (néon), D (BD), E (jour couvert), F (fin de journée).
Assets : Kenney (CC0), polices Google Fonts (OFL), FreeSerif (GPL + exception de police).
